# Insurance Claims & Fraud Analysis Dashboard

## Project Overview
Built an interactive Power BI dashboard to analyze insurance claims, fraud trends, claim severity, and regional risk insights. Used Power Query, DAX, and data modeling to create KPI cards, dynamic visuals, and business-driven reporting.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Key Features
- KPI Dashboard
- Fraud Analysis
- Claim Severity Analysis
- City & State-wise Insights
- Interactive Filters & Slicers
- Data Modeling
